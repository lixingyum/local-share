这是一个基于 Python Flask 和 SocketIO 构建的“共享暂存板”应用。它允许你在局域网内的设备间快速传输文本、图片和文件。

以下是该应用的功能说明及部署指南：

### 🚀 功能亮点

* **多端同步**：通过 WebSocket (SocketIO) 实现数据实时推送，无需刷新页面。
* **智能粘贴**：支持直接粘贴文本或图片（Ctrl+V），图片会自动上传。
* **身份识别**：自动识别局域网内的设备为“管理端”或“共享端”，管理端可查看历史文件。
* **跨平台兼容**：代码中包含针对 Termux (安卓终端环境) 的 IP 获取适配。
* **文件管理**：支持文件上传、下载、复制文本/图片到剪贴板。

---

### 🛠️ 部署与运行

#### 1. 环境准备

你需要安装 Python 3 以及以下依赖库。你可以使用 `pip` 来安装：

```bash
pip install flask flask-socketio werkzeug
```

#### 2. 代码保存

将你提供的代码保存为 `app.py`。

#### 3. 运行应用

在终端执行以下命令启动服务：

```bash
python app.py
```

#### 4. 访问地址

根据你的需求选择访问方式：


| 访问端类型            | 访问地址                   | 权限说明                                   |
| :-------------------- | :------------------------- | :----------------------------------------- |
| **管理端**(电脑/手机) | `http://你的服务器IP:4001` | 可查看所有历史文件，有“显示全部文件”按钮 |
| **共享端**(访客)      | `http://你的服务器IP:4001` | 仅显示最近 10 分钟的内容                   |

> **注意**：代码默认监听 `0.0.0.0:4001`。请将“你的服务器IP”替换为运行此代码的机器在局域网中的真实 IP 地址（如 `192.168.1.100`）。

---

### 📂 数据存储说明

应用运行后，会在当前目录自动生成以下文件/文件夹：

* **`shared_files`**：存放所有上传的文件、图片和文本。
* **`metadata.json`**：记录文件的元数据（如文件名、类型、时间戳等）。

---

### 📝 使用场景示例。

1. **传文本**：复制一段代码或文字，发送到暂存板，另一台设备即可复制使用。
3. **传文件**：点击“选择文件”按钮上传，接收方点击“下载”即可。

该脚本开箱即用，非常适合在没有网络传输工具或需要快速共享内容时使用。
